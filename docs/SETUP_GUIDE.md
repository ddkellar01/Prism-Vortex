# PrismVortex Setup & Installation Guide

## Prerequisites
- **Python 3.11+** installed on your system.
- **Docker & Docker Compose** for containerized deployments.
- A valid **Google Gemini API Key** with access to high-horizon models (`gemini-4-argon`).
